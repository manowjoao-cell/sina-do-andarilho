# Sina do Andarilho

Jogo incremental de cartas para navegador: um herói, uma estrada sem fim, hordas, cartas com raridades, itens, habilidades e ranking.

Jogue em: https://manowjoao-cell.github.io/sina-do-andarilho/

- `index.html`: o jogo inteiro (um único arquivo).
- `firestore.rules`: regras de segurança do ranking e das sugestões no Firebase.
